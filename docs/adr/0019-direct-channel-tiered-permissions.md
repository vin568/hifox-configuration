# 直连通道三级权限：只读自由、变更白名单、白名单外请示

三条执行通道中，直连通道（宋江自跑命令、不经能力 agent）的权限形态是真权衡：严格白名单做不了临时的事，「不像 super agent」；完全放开则爆炸半径不可控——首期就跑在个人 Mac 上，后续迁内网机器。

**决策：**

- **三级制**：
  1. **只读自由**：无副作用命令（查文件、git log/status、进程、只读 HTTP 查询）宋江自判执行，逐条记入作业台账；对「是否无副作用」没把握时降级到第 3 级。
  2. **变更走白名单**：`super-agent/direct/` 一脚本一文件，参数透传；新增白名单 = 改本仓走 git。
  3. **白名单外的变更请示**：私聊上报用户，批准后执行并记账。
- **硬禁区闭集**（任何级别不碰）：删除类命令、安装软件、动本仓以外的 git、读取任何凭证/密钥、对外发送（只允许经 `superctl reply`）。
  **修订（ADR 0031，2026-11-20）**：受控外发通道增加 `superctl answer`（把用户回答投进平台任务对话）；除这两条外仍无第三条。
- 权限面写进宋江提示词与能力目录页；蒋敬复盘定期抽查直连记账，越权模式进能力缺口提案。

**Considered Options：**

- **严格白名单（原案，直连只能跑列明脚本）**：拒。用户裁定过死——「做不了这做不了那，不像 super agent」。
- **全放开 + 事后审计**：拒。爆炸半径不可控，事后审计救不回已破坏的现场。

**Consequences：**

- 「只读」由宋江判定，存在误判空间：靠全量记账 + 复盘抽查兜底，拿不准即降级请示。
- `super-agent/direct/` 白名单目录成为新的能力面，README 与用例随仓维护。
