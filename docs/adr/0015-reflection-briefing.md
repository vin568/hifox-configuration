# 自省播报：统筹入口的每日主动推送

ADR 0013 把夜间自省的出口定为「反思者不碰飞书，吴用在下次前台会话开头转述摘要」——转述时机绑定用户主动发起对话：用户不来问，摘要就一直躺在总览里。用户明确要求吴用主动把每日自省结果送上门。约束不变：反思者保持只读、不面向用户（0013）；吴用是唯一对外交互面（ADR 0007 对外口径）；后台任务零打扰（台账巡检先例）；不引入新的台账 / 文档形态（ADR 0005 一事项一文档）。

**决策：**

- **新增 automation `wuyong-reflection-briefing`**（`assignee: agent:wuyong`，每日 09:00 Asia/Shanghai，两个环境各一份实例）：读同层级《自省总览》，`最近成功` ≤24h 时按对外口径私聊播报 ≤6 行摘要（趋势、异常、建议要点 + 提议编号 +「采纳第 N 条」邀请）；无活动只报一行；陈旧不发——陈旧与连续 2 晚失败仍由前台会话提示（0013 口径不变）。每日至多一条。
- **裴宣与 0013 边界零改动**：反思者仍不私聊、不建任务、权限面不动；播报者与转述者都是吴用，对外唯一交互面不变。
- **去重不新增状态，全部用平台事实 + 时间规则**：
  - 播报侧：`最近成功` 之后已有同层级吴用已完成的前台 chat 会话 run → 该版本已在前台转述过，跳过；只认用户消息触发的 run，排除 automation run（含自身与巡检），查询失败或触发类型不可辨时照播（宁重勿漏）。
  - 前台侧（instructions §0 会话第一件事（续））：`最近成功` 晚于今日 09:00、或当前还没到今日 09:00 → 给 5 行摘要；当前已到 09:00 且 `最近成功` 不晚于 09:00 → 视为已被播报覆盖，一句话确认（不断言用户已收到，带重发入口）。
- **09:00 是三处同步不变量**：automation.yaml 的 cron、吴用 instructions 的前台时间界、automation description 的去重说明；改时间三处同改。
- **投递走飞书会话，不走 `--to` 直聊**：agent 运行主体 `--to` 直聊 owner 命中平台 400 `self-conversation not allowed`，且 automation run 的 `auth status` 无 `email`、`triggerHuman` 为空（2026-11-13 staging 首跑实证，首跑曾自作主张发进 run 自身绑定会话并误报 `notified=true`，已明令禁止改道）。正确路径：从自己的 run 列表解析最近 `chat` 面 run 的 `chatSession.id`，`chat message send <会话 id>` 发进与用户的飞书直聊；解析不到会话或发送失败 → `notified=false`。巡检 `wuyong-ledger-sweep` 的上报路径同源同修。

**Considered Options：**

- **让裴宣直接私聊**：拒。0013 明确反思者不面向用户，`directMessage` 权限全关；开权限破坏只读最小权限面。
- **并入 `wuyong-ledger-sweep`**：拒。巡检契约是窄的（只对账「进行中」、无变更零打扰），30 分钟节奏与每日播报的消息预算不同；0013 拒绝混合任务的先例同构。
- **在会话内主动发消息（无 automation）**：拒。平台持久会话没有「无人触发主动发言」的入口；定时 automation 是唯一主动面。
- **用台账事项或新文档记播报状态做去重**：拒。台账是一事项一文档的调度状态，播报记录不是事项，放进「进行中」会被巡检当幻影对账；为此新增文档形态收益为负——平台 run 元数据 + 时间规则已足够。

**Consequences：**

- 吴用名下多一个 automation（staging / prod 各一份，`state.yaml` 登记）；先 staging 观察 1–2 个晨间运行（收件人解析、消息行数与对外口径），再 prod 放量。
- 播报当日失败（automation 未跑 / 发送失败）用户会错过当条：`notified=false` 留在 automation 输出，前台一句话确认里带重发入口（不断言用户已收到），次日新版本恢复推送；可接受，不做重试队列。ADR 0013 的 48h 前台摘要保证由此带一个例外：按 09:00 时间界判定为已覆盖的版本，前台只确认不重述。
- 提议编号沿用反思者 skill 的口径（按影响排序编号，播报与「采纳第 N 条」同编号），采纳后流程不变（吴用 instructions §3 改进项决策事项）。
- 术语入 `GLOSSARY`（自省播报）；README 统筹调度节同步。

**依据：** 本仓 ADR 0005（台账形态）、0007（对外口径）、0013（夜间自省与反思者边界）；先例 `wuyong-ledger-sweep`（私聊上报、收件人解析、零打扰）。
