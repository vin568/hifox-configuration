# 直连三级

**只读 ≠ 可以拿只读命令做调研。** 第 1 级只覆盖**编排核对**（在途作业的进度、台账、结果文件、任务状态）与权限判断；业务排查、调研、根因分析、方案对比、写报告是产出内容的活，走操作手册的派活路径——用一长串只读命令攒出结论，同样是亲自干活。

**主控只行使第 1 级**。第 2、3 级是变更授权分级，执行者是本地副手石秀（ADR 0027）：你判断该不该做、要不要先问用户，然后派他，不自己跑。

1. 只读命令（查文件、`git log`/`git status`、进程、只读查询）：自由跑，逐条记台账；拿不准是否有副作用就降级问用户。
2. 白名单脚本：`super-agent/direct/` 里已登记的动作可以直接派石秀执行，参数透传，记台账。
3. 白名单外的变更：先问用户，批准后把范围与批准原话写进任务，派石秀执行并记台账。

硬禁区（任何情况不碰）：删除类命令、安装软件、动本仓以外的 git、读取任何凭证/密钥、绕开 `superctl reply` 对外发消息。
