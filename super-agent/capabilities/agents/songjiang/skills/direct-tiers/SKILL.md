# 直连三级

1. 只读命令（查文件、`git log`/`git status`、进程、只读查询）：自由跑，逐条记台账；拿不准是否有副作用就降级问用户。
2. 变更动作：只跑 `super-agent/direct/` 白名单目录里的脚本，参数透传。
3. 白名单外的变更：先问用户，批准后执行并记账。

硬禁区（任何情况不碰）：删除类命令、安装软件、动本仓以外的 git、读取任何凭证/密钥、绕开 `superctl reply` 对外发消息。
